# FinMan v2.2.1.3 — Changelog

---

## ✨ New Features

### Credit Card Account Type
- Added **Account Type** field (Regular / 💳 Credit Card) with Settlement Date and Payment Due Days.
- Live billing cycle preview and due date shown while editing.

### Credit Card Billing Cycle View
- CC accounts show two-column rows: **Balance Payable** and **Outst. Balance**.
- Overpayments display as a green `+` credit amount.

### CC Cycle Period in Account Drill-down
- CC accounts default to a **CC Cycle** period tab scoped to the current billing cycle.
- Navigable with ‹ › arrows; **Current** badge marks the live cycle.

### Credit Card Payment Due Date Alerts
- Alert banner on Accounts screen when a CC payment is due within 7 days (🔔/⚠️/🚨).
- Due date dot on each CC account row showing days remaining.

### Running Balance in Account Drill-down
- Cumulative balance shown after each transaction in brackets — e.g. `(₹9,67,413)`.
- Most recent transaction of the period shows `(Balance ₹9,67,413)`.

### Backup Feature
- **Backup Now** saves a full JSON backup to device, logged in history (last 3 kept).
- **Auto Backup schedule** — Daily / Weekly / Monthly. Reminder banner on app open when overdue.
- Google Drive row shown as Coming Soon.

### Full Backup Export / Import (JSON)
- Export includes transactions + accounts, groups, mappings, categories, budgets.
- Import from Full Backup JSON automatically restores all settings before transactions.
- **Merge** is the recommended import mode — preserves existing data, adds only new rows.

### Searchable Chip Picker for Account / Category / Subcategory
- Native dropdowns replaced with a bottom-sheet chip picker.
- **Recent** section (last 5 auto-computed) shown as pill chips at the top.
- **All** section shown as a 3-column chip grid in user-defined order.
- Subcategory also uses chip grid. Tap "⠿ reorder in Settings" to reorder without leaving the form.

### Configurable Content Font Weight
- Light / Regular (default) / Bold selector in Settings → Appearance.
- Applies to transaction notes, amounts, account names, category names — not structural text.
- Live preview updates instantly.

### Dynamic Chart Windows
- Trend charts in Account and Category drill-downs anchor to the viewed period (Month/Year/FY).

### Grouped Settings
- Settings → Accounts list grouped by Account Group with drag-to-reorder.
- Profile card moved to top of Settings screen.

## 🐛 Bug Fixes

### Add Transaction UX
- Account picker opens automatically as first field on form open (add mode).
- Selecting Category immediately opens Subcategory picker when options exist.
- Selecting "None" for subcategory advances to Amount — no longer loops.
- Smart focus flow skips already-filled fields; goes to the next empty required field.
- Amount field moved below Category/Subcategory; keyboard Enter on Amount advances to next empty field.
- Transfer type shows **⇄ Swap** button to swap From/To accounts.
- Reorder overlay opens inline — Back returns to the form with state intact.

### Import / Export
- CSV parser rewritten as RFC 4180 tokeniser — handles multiline quoted fields correctly.
- CSV exporter quotes fields containing newlines (RFC 4180 compliance).
- Phantom accounts (`INR`) and UUID category names filtered on import.
- Case-insensitive category dedup on import merge.
- Category drag order now persists correctly (sortOrder saved to DB).
- Account picker respects Account Group order from Settings.
- `accountMapping` was always empty in JSON export — fixed.
- Copy transaction "original date" option was always using today's date — fixed.

### UI Fixes
- Subcategory percentage badges always shown (including 100% for All row), colour-coded.
- Font weight selection now reflects immediately in Appearance screen.
- Note ✕ clear button visible on focus, not only after typing.
- Backup due banner correctly appears after schedule is set (lastBackupCheck no longer reset on schedule change).
- Category sort order persists after drag reorder in Settings.

## 🏗 Notes
- DB schema: `accounts` table extended with `acct_type`, `settlement_date`, `payment_due_days`. IndexedDB version bumped to `7`.
- CSV import is transactions-only. Use **Export Full Backup (JSON)** for full portable backup.
- Google Drive backup requires Google Cloud OAuth setup — planned for a future release.
- Version: `2.2.1.3`
