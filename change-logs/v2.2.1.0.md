# FinMan v2.2.1.0 — Changelog

Released after v2.2.3 internal build series. First version pushed to GitHub by Akbar.

---

## 🐛 Bug Fixes

### Transaction Detail — Bottom Sheet
- Buttons (Close / Edit / Delete) were hidden behind Android device navigation bar
- Root cause: `env(safe-area-inset-bottom)` returning 0 in Capacitor WebView
- Fix: `html[data-cap-android]` CSS rule now sets `--safe-bottom: 56px`; JS probes measure precise value after paint and inject it. Bottom sheet uses `margin-bottom: var(--safe-bottom)` to float above nav bar

### Transaction Detail — Edit on Tap
- Tapping anywhere on the amount or field area of the detail popup now opens the Edit form directly (previously required explicit Edit button)

### Search — Period Nav Centring
- Period navigation bar (‹ Month › ) was left-aligned
- Fix: Removed horizontal padding from `.period-nav-bar`, made inner container `width:100%; justify-content:center`

### Transactions Monthly View — Future Year
- `›` arrow was capped at `now.getFullYear()` preventing navigation to future years
- Fix: Removed `Math.min` cap — all period navigation now unrestricted in both directions
