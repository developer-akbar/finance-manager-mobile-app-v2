# FinMan v2.2.1.1 — Changelog

---

## 🐛 Bug Fixes

### Saving Rate — Wrong Calculation
- Was using current month income (e.g. ₹215) as denominator → result was e.g. −27,081%
- Fix: Now uses **all-time total income vs total expense** for a meaningful portfolio-level saving rate
- Negative rate displays as `−X% (spending exceeds income)` with correct red bar

### AddTransaction — Left/Right Layout Cut-off
- Form was overflowing horizontally on some screen sizes
- Fix: Explicit `left:0; right:0` on `.fullscreen-modal` to prevent edge overflow with `max-width:480px; margin:0 auto`

### Future Period Navigation Restricted
- Monthly view `›` year button capped at `now.getFullYear()`
- FY navigation in Categories and Accounts also capped
- Fix: All `Math.min(...currentFY())` and `Math.min(...getFullYear())` caps removed — navigate freely in both directions

---

## ✨ New Features

### Swipe Gestures — Period Navigation
- Swipe **left** → next period (same as ›); swipe **right** → previous period (‹)
- Works on: Transactions daily view, Search view, Account detail, Category detail
- Horizontal swipe only triggers when dx > dy (prevents conflict with vertical scroll)

### Nav Re-tap Reset
- Tapping the **active** tab in the bottom nav resets that screen to its default state
- Transactions → resets to current month daily view
- Accounts → back to accounts list (exits any drilled account)
- Categories → back to categories list
- Settings → scrolls back to top
- Implemented via React `key=` remount on each nav re-tap

### Accounts Detail — Add Transaction Button
- `+` FAB button in account detail header
- Tapping it opens Add Transaction with the **account pre-filled**
- Tapping a date group header also opens Add Transaction with account + date pre-filled

### Categories Detail — 6-Month Trend Chart
- Line chart showing monthly spend trend for the last 6 months
- **Dynamically updates** when a subcategory filter is selected (chart shows subcategory trend)
- Works for both category-level and subcategory-level drill-down

### Search Filters — Categories Grouped by Type
- Categories in the filter popup now split into **Expense** and **Income** sections with colour-coded headers
- Filter popup height increased to `92dvh` for more visibility

### Default Seed Data
- Fresh installs now automatically populate with:
  - **5 Account Groups**: Bank Accounts, Cash, Credit Cards, Investments, Loans
  - **11 Accounts**: HDFC Savings, SBI Savings, ICICI Current, Cash Wallet, HDFC Credit Card, SBI Credit Card, Zerodha/Stocks, Mutual Funds, PPF, Home Loan, Car Loan
  - **12 Expense Categories** with subcategories: Food & Dining, Transport, Shopping, Bills & Utilities, Health, Education, Entertainment, Home, Family, Finance, Investments, Miscellaneous
  - **4 Income Categories** with subcategories: Salary, Business, Investment Returns, Other Income
- All seed data is fully editable — users can rename, delete, and add more

### Kanban — Intra-Column Reordering
- Previously, dragging within the same Kanban column had no effect
- Fix: Cards now highlight their drop target with a green top border; dropping reorders the card within the column
- Reorder is saved immediately via `onReorder` callback

### Settings — About
- Updated to: `v2.2.1.1 — Built for you by Akbar 💚`

## 🎨 App Icon — Adaptive Icon Fix

### Root Cause
- `ic_launcher_foreground.png` is the foreground layer used by Android 8+ adaptive icons
- `copy-icons.sh` previously only copied `ic_launcher.png` and `ic_launcher_round.png`
- The Expo/Capacitor default `ic_launcher_foreground.png` was never replaced → home screen showed Expo icon

### Fix
- New `icon-foreground-*.png` files generated for all densities (transparent background, FinMan ₹ logo)
- `copy-icons.sh` updated to also copy foreground files to all `mipmap-*` folders
- After running `bash copy-icons.sh`: **Build → Clean Project → Rebuild Project → Run** in Android Studio
