# FinMan v2.2.1.2 — Changelog

---

## 🐛 Bug Fixes

### Back Button Behavior (Multimode)
- Fixed back button handling when multimode is enabled in the mobile app, stopping unintentional screen exits.

### Device Back Button — Transaction screens
- Fixed issue where device back was not correctly intercepted on Add/Edit/View transaction modals.

### Account Transaction Rollup
- When viewing an account, transfer rows are now correctly treated as income/expense for that account, not a generic transfer row.

## ✨ New Features

### Export (Capacitor mobile) — CSV/JSON
- Added Capacitor-aware file save implementation for mobile.
- Users can export transaction data as CSV/JSON directly from the app on device storage.

### Splash Screen
- Added app splash screen before main content loads to improve startup UX.

### Add Transaction: Continue + Copy
- Added “Continue” and “Copy” actions to Add Transaction popup for rapid entry of multiple transactions.

### Multi Select in Transaction List
- Added long-press multi-select for Transactions in list views, enabling bulk actions across components.

### UI: Appearance updates
- Added app-wide font family updates and polished styling for a cleaner look.

### UX: Date header spacing + scroll
- Added spacing between date header groups and a “Scroll to current date” header utility.

- This release improves mobile UI/UX and fixes key navigation flow bugs.
